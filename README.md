# Blood Pressure Monitor UI - LVGL

## Overview

This project is a beginner-friendly LVGL (Light and Versatile Graphics Library) application developed on Ubuntu/WSL using the LVGL PC Simulator.

The project demonstrates:

* LVGL Simulator Setup
* Label Creation
* Button Creation
* Event Callback Handling
* Dynamic UI Updates
* Embedded GUI Development Fundamentals

This project is part of my Embedded Systems and LVGL learning journey.

---

## Features

### Current Features

* Display custom text on screen
* Create interactive buttons
* Handle button click events
* Update UI elements dynamically
* Run LVGL application on PC Simulator

## Build Instructions

Configure Project

```bash
cmake -B build
```

Build Project

```bash
cmake --build build -j4
```

Run Application

```bash
./bin/main
```
